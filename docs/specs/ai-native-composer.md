# AI authoring contract

The original composer-only proposal has been superseded by [Ideate](../development/ideate.md) and [client reviews, series, and batch scheduling](../development/client-reviews-and-series.md). Use those maintained contracts for the current entry points, four-option generation, source permissions, durable recovery, and review rules.
