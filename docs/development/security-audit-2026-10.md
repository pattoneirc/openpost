## Historical High findings (9)

### H1 Session JWT in JSON + Bearer bypasses cookie protections — `apps/server/internal/api/handlers/auth.go:2011-2014`, `middleware/auth.go:300-309`

- Exploit: XSS/extension reads JSON token, replays cross-site via Authorization header, no Origin check. Full takeover incl. instance-admin.
- Status: REPRODUCED 2026-10-12. issueAuthResponse sets Body.Token + HttpOnly cookie (auth_test.go:207-210 proves duality). OIDC handoff also leaks (oidc.go:272,761). Correction: impersonation-consume is cookie-only (instance_admin.go:723-725), not affected. Bearer path cookieAuth=false skips Origin check; PrincipalCanAccessREST passes empty scope. CLI uses separate op_cli_ family, browser uses credentials:include — removing Body.Token breaks nothing.
- Fix direction: cookie-only for browser flows; reserve body token for native/CLI op_cli_; or reject SessionID-bearing principal via header, enforce Origin regardless of transport.
- Pattern: transport confusion.

### H2 XFF-spoofable IP rate limit, in-memory only — `middleware/auth.go:645-647`, `services/ratelimit/limiter.go:8-65`

- Exploit: rotate X-Forwarded-For per request to defeat login/mfa/register limits; scale x replicas.
- Status: REPRODUCED 2026-10-12 with /tmp/xff-poc (fixed IP denies at 21, rotating 0/200). First-entry wins, no Trusted/CIDRs, no e.IPExtractor. login:email still caps single-account, bypass enables spray + mass registration. Web/worker separate maps. Deploy/proxy docs append not strip.
- Fix direction: OPENPOST_TRUSTED_PROXY_CIDRS, right-to-left walk else RemoteAddr; shared store fail-closed; doc proxy stripping.

### H3 Passkey verify no rate limit + orphaned login_mfa — `handlers/auth.go:840-949`

- Exploit: unlimited WebAuthn attempts with stolen mfa_token; parallel methods.
- Status: REPRODUCED 2026-10-12. TOTP/recovery have mfa:ip+user limits, Begin/Finish passkey have zero allowAuthAttempt, Errors omits 429. Finish input has no mfa_token field, deletes only child row, parent login_mfa survives 10min reusable across all factors. TOTP also get+delete non-atomic.
- Fix direction: limits on both passkey endpoints + atomic consumeChallengeWithDB parent+child in one Tx, single-flight Begin.

### H4 Quota TOCTOU — check-then-increment — `handlers/publications.go:1105,1141`, `handlers/media.go:3777,1796`, `services/publisher/publisher.go:1148,1182`, `services/usage/service.go:30,42`

- Exploit: burst N parallel at limit-1, all pass, all increment.
- Status: REPRODUCED 2026-10-12 on 6/7 paths (workspaceteam Invite serialized via workspace row lock but not atomic). Increment is blind upsert, no WHERE value+n<=limit. Check pure reads, increments separate tx/requests. Widest: direct-upload check at create vs increment at complete; publisher post-publish increment.
- Fix direction: atomic guarded upsert WHERE value+n<=limit RETURNING, RowsAffected==0→402; reserve-then-publish with compensate; COUNT+INSERT same tx with row lock.

### H5 Paddle charge never reconciled — `services/billing/service.go:959-993,1154-1163`

- Exploit: agency attempt + founder price ID in inline checkout, get agency limits. Monthly/annual swap.
- Status: REPRODUCED (static + test outline 2026-10-12). `resolvePaddleSubscription:974-975` takes `planID=attempt.PlanID`, `priceID` from subscription side-by-side, never compares. `attempt.ProviderPriceID` written at create never read on webhook. Browser gets full `PriceIDs` map via `checkoutResponse`. `ResumeCheckout:383-385` checks mismatch but webhook path has no equivalent.
- Fix direction: fail-closed compare `priceID == attempt.ProviderPriceID` + `priceID in Plan.PaddlePriceIDs[period]`; reject unknown; don't fall back to attempt plan on mismatch.
- Pattern: client-controlled billing signal trusted.

### H6 preview-text-card no rate limit — `handlers/publication_text_cards.go:51`, `textcards/layout.go:93-94`, `textcards/render.go:60`

- Exploit: parallel 2200-char + 35 attachments, 10 pages each with Blur22 + JPEG, no 429/queue. Save fans out inside DB tx.
- Status: REPRODUCED 2026-10-12. Zero limiter hits vs memes 30/min+semaphores. Preview takes tx handle, loops renditions x segments, RefreshSegment does Layout+Render+blob+inserts. 10x 1080x1350/1920 + Blur22 + Q94 sync in-tx + avatar fetch. Autosave 2s debounce + preview 350ms debounce hit it.
- Fix: per-user rate on preview (mirror meme), concurrency semaphore with 429-busy, move render/persist out of tx (fingerprint in-tx, job outside).

### H7 Workflow approval-to-schedule not bound — `services/workflows/runs.go:200`, `handlers/workflow_actions.go:108-161`

- Exploit: approve A, schedule arbitrary B/revision. Docs claim violated.
- Status: REPRODUCED (static 2026-10-12). `Approve` takes ID from run but revision from caller (`runs.go:200`); `schedule():130-162` reads arbitrary inputs, no run-state compare; `definition.go:225` requires presence not reference; zero cross-validation hits. Happy path uses `reference("review.*")` (service_test.go:152-181) but literals succeed.
- Fix direction: persist approved {id,revision} in run at Approve; equality-check at schedule admission; definition-time warn on literals is defense-in-depth only.
- Pattern: missing binding at irreversible action.

### H8 No workflow AI spend cap — `services/workflows/external_effects.go:111-155`

- Exploit: interval(5m)+ai chain, maxActiveRuns=1000, each 2048 tokens/90s, no cap check.
- Status: REPRODUCED (static 2026-10-12). `generate()` INSERTs running row then calls provider, never SELECTs/SUMs `workflow_ai_usage`; repo-wide grep zero enforcement hits. `maxActiveRuns=1000` caps run count not spend; one run 40 steps. `workflow_ai_usage` table exists but nothing reads it for billing; `services/usage` has zero workflow/AI hits. Closest knobs are X-only.
- Fix direction: pre-flight SUM(cost,tokens) month-bound vs new `workflow_ai_monthly_microusd` entitlement, typed ErrAIBudgetExceeded; kill-switch `OPENPOST_WORKFLOWS_AI_ENABLED` + operator monthly hard-stop.
- Pattern: unbounded third-party cost.

### H9 Live secrets on disk (untracked) — `/.env:1-2`, `apps/server/.env`, `openpost-release.jks`

- Status: CONFIRMED hygiene gap 2026-10-12, NOT active leak. gitignored (*.env, _.jks), not tracked. git add -A safe, risk is add -f / tar / artifact log-tail embedding. CI globs narrow, no direct .env glob. No bundle deny-list. Boot rejects change-this-_ for JWT/encryption (log.Fatal), Paddle/OAuth/OpenRouter empty=disabled later.
- Fix: rotation if ever exposed + bundle deny-list test + tar exclude docs + secret-manager path.

## Patterns emerging (to validate in wave 2)

1. **TOCTOU / check-then-act**: quota, imports budget RMW, idempotency empty-WS fill, Tx reload w/o re-check, first-workspace SQLite, stat-then-upload.
2. **Transport/confused-deputy**: session JWT Bearer vs cookie, cli:full on MCP, rendition account ID trusted at publish, instance bot tokens keyed only by guild/chat string, local-upload ticket SessionID never verified.
3. **Client-controlled signals trusted**: XFF/XFP, tone/media-preference as instructions, unlocked model choices becoming authoritative, Paddle custom_data/price IDs, ToneAdjustment persistent instructions.
4. **Error oracle / info disclosure**: 404-vs-403, raw DB/provider errors, fs.Stat leak, validation reflection, timing oracle, enumeration oracles.
5. **Expensive without gate**: text-card render, AI repair fan-out, workflow AI no cap, image 256MB x3 decodes, 16GiB late quota, WASM per-eval caps but no global bound.
6. **Secret sprawl/persistence**: tokens in URL (?token=, access_token=), hardcoded workflow secrets in snapshots (30d immutable), run outputs to viewers, build request_json to readers, preview bytes linger, MCP ticket model-visible.
7. **Missing second layer**: no RLS, no publish-time re-check, no KDF, no global body limit/timeouts, no RLS equivalent for jobs (JOIN-derived).

## Fix rationalization (reuse across findings — details per finding in wave 2)

- Atomic guards: `WHERE value+n<=limit` or advisory lock + return allowed/denied; never check-then-increment across tx.
- Re-authorize at irreversible boundary: publish/schedule/revoke/replay must reload workspace-scoped rows with `AND workspace_id=?` inside same tx/lease.
- Transport binding: cookie-session ≠ Bearer; scope defaults fail-closed (`mcp:read`); revoke must cover all token systems.
- Trust boundaries: derive IP/secure only from trusted hops (config CIDRs); reject client network signals by default.
- Error hygiene: map to codes (`failed`, `limit_exceeded`) at handler edge; never `err.Error()` with DB/provider text; constant-time dummy bcrypt.
- Cost gates: rate limit + concurrency limiter + budget on every CPU/AI/egress path (mirror memes.go pattern); move work out of DB tx.
- Secret hygiene: no secrets in URLs/logs/snapshots; exact+encoded redaction (url/hex/unicode/split); KDF (argon2/hkdf separate contexts); enforce key strength.
- SSRF: default `netguard` for all outbound; no `platform.DoRequest` for user URLs; re-validate redirects; bound bodies (`LimitReader` + timeouts).
